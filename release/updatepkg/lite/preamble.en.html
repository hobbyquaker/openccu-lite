You are installing openccu-lite.

openccu-lite is a separate project based on OpenCCU, but it is not OpenCCU: no ReGaHSS, no WebUI programs or Homematic scripts, its own web interface and the system service occulited.

Support: please report questions and problems with openccu-lite only in openccu-lite's issue tracker: https://github.com/hobbyquaker/openccu-lite/issues - not in the OpenCCU forum and not in OpenCCU's issue tracker. The OpenCCU team cannot help with openccu-lite.

Donations: openccu-lite's maintainer does not accept donations. If you want to support the project, give it a star on GitHub: https://github.com/hobbyquaker/openccu-lite. The donation buttons in OpenCCU's text below go to OpenCCU's developers, not to openccu-lite's maintainer.
