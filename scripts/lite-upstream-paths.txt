# openccu-lite: upstream paths this fork does not carry, and upstream paths it has rewritten as
# its own. Upstream's release tags are merged into lite; a tag that changes one of these paths
# conflicts (modify/delete, or both modified), and a tag that adds a file under a removed
# directory brings it back. scripts/lite-upstream-merge.sh settles both after the merge.
#
# One git pathspec per line, after a keyword:
#   remove <pathspec>   never in lite: deleted again, whatever the merge brought
#   ours <pathspec>     lite's own version: taken from lite (HEAD) whole; a file upstream added
#                       under it is removed
# `:(exclude)<pathspec>` narrows the remove lines before it. Blank lines and # comments are ignored.
